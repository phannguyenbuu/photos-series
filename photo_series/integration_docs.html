1. Module Federation (Khuyên dùng)

Bạn có thể nạp trực tiếp component PhotoSeriesSection vào ứng dụng React (18 hoặc 19) mà không cần sao chép mã nguồn hay build lại mỗi khi module cập nhật. CSS của component được tách riêng và đóng gói dưới selector .photo-series-panel nên không làm lệch giao diện trang host.

1A. Host dùng Vite (@originjs/vite-plugin-federation)

Cài plugin: npm install -D @originjs/vite-plugin-federation, sau đó cấu hình vite.config.js:

Hoặc nạp động ở runtime mà không cần sửa cấu hình Webpack:

import React, { lazy, Suspense } from 'react';
import * as ReactDOM from 'react-dom';

function loadRemotePhotoSeries() {
  const URL = 'https://toolxprint.com/modules/photo-series/remoteEntry.js';
  return new Promise((resolve, reject) => {
    if (window.remote_photo_series) return resolve();
    const s = document.createElement('script');
    s.src = `${URL}?_t=${Date.now()}`;
    s.onload = () => resolve();
    s.onerror = () => reject(new Error('Không thể tải remoteEntry.js'));
    document.head.appendChild(s);
  }).then(async () => {
    const container = window.remote_photo_series;
    await container.init({
      react: { [React.version]: { get: () => Promise.resolve(() => React), loaded: 1, eager: true } },
      'react-dom': { [React.version]: { get: () => Promise.resolve(() => ReactDOM), loaded: 1, eager: true } },
    });
    const factory = await container.get('./PhotoSeries');
    const mod = factory();
    return { default: mod.default || mod.PhotoSeriesSection };
  });
}

const RemotePhotoSeries = lazy(loadRemotePhotoSeries);

export function PhotoFilterWidget() {
  return (
    <Suspense fallback={<div>Đang nạp Ảnh theo series…</div>}>
      <RemotePhotoSeries showDocsButton={false} syncUrlQuery={false} />
    </Suspense>
  );
}
Khi nhúng bằng Module Federation, trình duyệt chạy mã dưới origin của website host. Do đó cần thêm origin của website bạn vào web.allowed_origins trong PrintAgent (xem mục 6).

4. Kiến trúc hoạt động

Người dùng chọn một thư mục ảnh (JPEG, RAW, ARW) trên máy của họ. PrintAgent — chương trình chạy nền tại http://127.0.0.1:9173 — đọc ảnh và EXIF, nhóm các ảnh cùng lần chụp, chấm điểm kỹ thuật và chọn N ảnh đẹp nhất trong mỗi nhóm. Việc này chạy hoàn toàn trên máy người dùng, không sửa ảnh gốc.

Để có câu mô tả ngữ cảnh, agent chỉ gửi một thumbnail nhỏ của ảnh đại diện mỗi nhóm lên máy chủ phân tích ngữ cảnh. Máy chủ ghép nhiều nhóm vào một lưới (tối đa 16 ô) để trả lời nhanh, rồi trả về ngữ cảnh, số người và vị trí khuôn mặt cho từng nhóm.

5. Cài PrintAgent

Người dùng cần cài PrintAgent trên máy Windows của họ:

Tải trình cài PrintAgent

Trình cài tải agent mới nhất, kiểm tra kích thước và SHA-256 trước khi thay bản đang chạy. Agent cần khoảng 1 GB trống trên ổ C (bản cài khoảng 86 MB và phần giải nén vào %TEMP% mỗi lần chạy).

Kiểm tra agent đã sẵn sàng bằng GET /api/photo-series/health:

{"ready": true, "version": 3, "raw_supported": true, "analysis_images_per_series": 1,
 "cancel_supported": true, "grouping_version": 3}

Coi là sẵn sàng khi ready === true và version >= 3.

6. Origin, CORS & loopback

  • Agent chỉ nhận kết nối từ chính máy đó (127.0.0.1 / ::1).
  • Mặc định cho phép: https://dir.toolxprint.com, https://toolxprint.com, https://mzpic.com, https://app.mzpic.com, http://localhost:5174, http://127.0.0.1:5174. Website khác bị trả 403 {"error": "Origin không được phép"}.
  • Mọi request POST phải có header X-Photo-Series: 1; thiếu thì trả 403. Body JSON gửi kèm Content-Type: application/json.
  • CORS: agent trả Access-Control-Allow-Origin đúng origin của bạn, cho phép header Content-Type, X-Photo-Series và phương thức GET, POST, OPTIONS.

Cho phép website của bạn trên một máy

Thêm origin vào %APPDATA%\GoxPrintAgent\settings.json trên từng máy cài agent (cùng khóa với tab Preset máy in):

{
  "web": {
    "allowed_origins": ["https://shop.example.com"]
  }
}
Origin được so khớp chính xác (scheme + tên miền + cổng, không có đường dẫn). https://shop.example.com không cho phép http://shop.example.com hay https://shop.example.com.evil.test. Giá trị "*" bị bỏ qua.

Trang HTTPS gọi http://127.0.0.1 có thể làm trình duyệt hỏi quyền truy cập mạng cục bộ. Người dùng cần bấm cho phép một lần.

7. Quy trình một lượt (REST API)

  1. GET /health — kiểm tra agent.
  2. POST /pick-folder — mở hộp chọn thư mục của Windows trên máy người dùng, nhận đường dẫn. (Hoặc tự nhập đường dẫn nếu bạn đã biết.)
  3. POST /jobs với {folder, config: {n}} — bắt đầu nhóm và phân tích, nhận job_id.
  4. GET /jobs/{job_id} mỗi 2 giây cho tới khi running === false. Hiển thị tiến độ từ status, processed/total và số nhóm đã có ngữ cảnh.
  5. Hiển thị các nhóm (series), ảnh xem trước qua /images/….
  6. Tuỳ chọn: POST /jobs/{job_id}/cancel, POST /jobs/{job_id}/resume, POST /jobs/{job_id}/export.
Mỗi agent chỉ chạy một lượt tại một thời điểm. Một thư mục khoảng 1.100 tệp (570 lần chụp, khoảng 110 nhóm) mất khoảng 6–7 phút.

11. Ảnh xem trước & khuôn mặt

kindNội dung
thumbnailWEBP, cạnh dài tối đa 480 px, toàn khung — dùng cho lưới và danh sách
previewJPEG, cạnh dài tối đa 800 px. Với ảnh được chọn có vẽ elip đỏ đánh dấu vùng trung tâm
primaryWEBP crop trung tâm, chỉ có với ảnh đại diện

Mọi ảnh trong nhóm đều có thumbnail và preview (ảnh không được chọn được tạo ở lần xem đầu tiên). Dùng thẳng URL agent trong thẻ <img>:

<img src="http://127.0.0.1:9173/api/photo-series/jobs/{job_id}/images/{image_id}/thumbnail">

Vẽ khuôn mặt

faces là danh sách khung [x0, y0, x1, y1] theo tỉ lệ 0–1 của ảnh đại diện toàn khung (đã xoay theo EXIF). Đặt lớp phủ có cùng tỉ lệ original_width / original_height với ảnh rồi vẽ:

const frame = document.createElement('div');
frame.style.cssText = `position:relative;aspect-ratio:${img.original_width}/${img.original_height};height:240px`;
frame.innerHTML = `<img src="${thumbUrl}" style="width:100%;height:100%">`;
for (const [x0, y0, x1, y1] of faces) {
  const mark = document.createElement('span');
  mark.style.cssText = `position:absolute;left:${x0*100}%;top:${y0*100}%;`
    + `width:${(x1-x0)*100}%;height:${(y1-y0)*100}%;border:2px solid #2ecc40;border-radius:50%`;
  frame.append(mark);
}

12. Lọc tất cả ảnh (selected)

POST /jobs/{job_id}/export với {"count": 1|2|3} chép N ảnh hạng cao nhất của mỗi nhóm vào thư mục con mới selected trong thư mục ảnh (selected_2, selected_3… nếu đã có). Ảnh gốc giữ nguyên.

  • Cặp JPEG + RAW của cùng lần chụp được chép cả hai.
  • Bản chép JPEG được ghi ngữ cảnh vào EXIF (ImageDescription, XPComment, UserComment) mà không nén lại ảnh. RAW giữ nguyên, ngữ cảnh ghi vào tệp .xmp đi kèm.
  • Lượt nhóm sau tự bỏ qua các thư mục selected*.

Trạng thái trả về (theo dõi bằng GET mỗi giây cho tới khi status !== "running"):

{"status": "completed", "count": 2, "done": 14, "total": 14,
 "folder": "D:\\Anh\\Cuoi\\selected", "images": 14, "files": 28,
 "exif": 14, "sidecars": 14, "without_context": 0, "errors": []}

13. Ví dụ JavaScript thuần

const AGENT = 'http://127.0.0.1:9173/api/photo-series';
const post = (path, body) => fetch(AGENT + path, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'X-Photo-Series': '1' },
  body: body ? JSON.stringify(body) : undefined,
}).then(async r => { const data = await r.json(); if (!r.ok) throw new Error(data.error); return data; });
const get = path => fetch(AGENT + path, { cache: 'no-store' }).then(r => r.json());

async function agentReady() {
  try { const h = await get('/health'); return h.ready && h.version >= 3; }
  catch { return false; }
}

async function runFolder(n = 3, onProgress = () => {}) {
  const { folder, cancelled } = await post('/pick-folder');
  if (cancelled) return null;
  const { job_id } = await post('/jobs', { folder, config: { n } });
  for (;;) {
    const job = await get(`/jobs/${job_id}`);
    onProgress(job);
    if (!job.running) return job;
    await new Promise(r => setTimeout(r, 2000));
  }
}

async function exportBest(jobId, count = 1) {
  let state = await post(`/jobs/${jobId}/export`, { count });
  while (state.status === 'running') {
    await new Promise(r => setTimeout(r, 1000));
    state = await get(`/jobs/${jobId}/export`);
  }
  return state;
}

15. Bảo mật & dữ liệu

  • Ảnh gốc và đường dẫn tệp không rời khỏi máy người dùng, trừ khi chính trang web của bạn đọc và gửi đi. Kết quả có trường folder, path, source_files chứa đường dẫn trên máy người dùng — đừng gửi về máy chủ của bạn nếu không cần.
  • Agent chỉ gửi lên máy chủ ngữ cảnh: thumbnail toàn khung (tối đa 480 px) và crop trung tâm (tối đa 1280 px) của ảnh đại diện mỗi nhóm, kèm thumbnail một ảnh mỗi đoạn chụp khi cần tách nhóm theo người. Không gửi ảnh gốc độ phân giải đầy đủ.
  • Chỉ thêm origin bạn kiểm soát vào allowed_origins: mọi trang ở origin đó đều có thể mở hộp chọn thư mục, đọc ảnh xem trước và chép ảnh trên máy người dùng.
  • /pick-folder mở hộp thoại Windows trên máy người dùng; chỉ gọi khi người dùng bấm nút.
